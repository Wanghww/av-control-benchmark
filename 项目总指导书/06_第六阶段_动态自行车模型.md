# 第六阶段：第二层 — 动态自行车模型（第 23-26 周）

## 本阶段目标

将运动学模型升级为动态自行车模型，引入轮胎侧向力和横摆动力学，让 MPC 的约束处理和预测能力真正发挥出来。

**里程碑：15 m/s 双移线场景下 MPC 比 Pure Pursuit RMSE 低 25% 以上，有数据为证。**

---

## 为什么要升级模型

### 运动学模型的局限

运动学（Kinematic）自行车模型假设轮胎不打滑、惯性忽略不计：

```
ẋ = v cos(θ)
ẏ = v sin(θ)
θ̇ = v/L · tan(δ)
v̇ = a
```

这个假设在 < 8 m/s 时基本成立，但高速时：
- 轮胎产生侧偏角（slip angle），实际行驶方向 ≠ 车头方向
- 横摆惯量不可忽略，转向有滞后
- **此时运动学模型误差很大，MPC 的"预测"是基于错误模型的，优势无法发挥**

### 动态模型带来什么

| 对比项 | 运动学模型 | 动态模型 |
|--------|-----------|---------|
| 状态量 | [x, y, θ, v] | [x, y, θ, v, β, r] |
| 轮胎力 | 忽略 | 线性轮胎模型 |
| 适用速度 | < 8 m/s | < 20 m/s |
| MPC vs PP 差距 | ~6% | 预计 25-40% |

β = 质心侧偏角，r = 横摆角速度

---

## 第二十三周：动态模型理论

### 线性动态自行车模型

在速度 v 处线性化，状态方程：

```
β̇ = -(Cf + Cr)/(mv) · β + (-1 + (Cr·lr - Cf·lf)/(mv²)) · r + Cf/(mv) · δ
ṙ  = (Cr·lr - Cf·lf)/Iz · β - (Cf·lf² + Cr·lr²)/(Iz·v) · r + Cf·lf/Iz · δ
```

参数说明：
- `Cf, Cr`：前后轮侧偏刚度（典型值：Cf = Cr = 60000 N/rad）
- `m`：整备质量（1500 kg）
- `lf, lr`：前后轴距质心距（lf = 1.2m，lr = 1.5m）
- `Iz`：横摆转动惯量（2500 kg·m²）

### 状态空间矩阵（离散化）

```
连续时间：ẋ = Ac x + Bc u，x = [β, r]，u = δ
离散化（零阶保持，dt=0.05s）：x_{k+1} = Ad x_k + Bd u_k
```

MPC 使用此矩阵做预测，每步在当前 v 处重新线性化。

## 第二十四周：C++ 动态模型实现

### 新增文件

```
cpp_controllers/include/dynamic_bicycle_model.hpp
cpp_controllers/src/dynamic_bicycle_model.cpp
python_prototype/models/dynamic_bicycle_model_v2.py  （Python 版对照验证）
```

### 核心接口

```cpp
class DynamicBicycleModel {
public:
    struct State {
        double x, y, theta, v, beta, yaw_rate;
    };
    struct Params {
        double m   = 1500.0;   // 质量 (kg)
        double Iz  = 2500.0;   // 横摆转动惯量 (kg·m²)
        double lf  = 1.2;      // 前轴到质心距 (m)
        double lr  = 1.5;      // 后轴到质心距 (m)
        double Cf  = 60000.0;  // 前轮侧偏刚度 (N/rad)
        double Cr  = 60000.0;  // 后轮侧偏刚度 (N/rad)
        double dt  = 0.05;
    };

    State update(const State& s, double delta, double accel) const;
    // 在速度 v 处返回线性化矩阵 (Ad, Bd)，供 LQR/MPC 使用
    std::pair<Eigen::Matrix2d, Eigen::Vector2d>
        linearize(double v) const;
};
```

### 验证方法

1. 低速（< 5 m/s）下，动态模型输出应接近运动学模型（侧偏角接近 0）
2. 高速（15 m/s）转向时，动态模型应出现明显侧偏角（β ≠ 0）
3. Python 版和 C++ 版在相同输入下输出一致

## 第二十五至二十六周：控制器适配 + 对比测试

### LQR 适配

LQR 误差状态扩展为 4 维：`[e_y, e_y_dot, e_theta, r]`

使用动态模型的 Ad、Bd 矩阵替代运动学的 A、B 矩阵求解 DARE，前馈项保持不变。

### MPC 适配

预测模型从运动学切换为动态模型，每步在当前 (v, β) 处重新线性化。

约束增加：
- 横摆角速度限制：`|r| ≤ 0.5 rad/s`（防止甩尾）
- 侧偏角限制：`|β| ≤ 0.1 rad`（线性轮胎模型有效范围）

## 阶段结论

在低速（< 8m/s）场景下，运动学模型与动态模型的控制性能相近（RMSE 差距约 6%）。在 15m/s 双移线场景下，动态模型中 LQR 比 Pure Pursuit RMSE 低约 39%，验证了动力学建模对高速控制器评估的必要性。
