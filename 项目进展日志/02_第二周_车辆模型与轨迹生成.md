### 动态自行车模型（dynamic_bicycle_model.py）

模拟真实四轮车横向动力学，包含轮胎侧偏力和横摆动态。

**车辆参数：**
| 参数 | 值 | 含义 |
|------|-----|------|
| m | 1500 kg | 整备质量 |
| Iz | 2500 kg·m² | 绕 z 轴转动惯量 |
| lf | 1.2 m | 质心到前轴距离 |
| lr | 1.5 m | 质心到后轴距离 |
| Cf = Cr | 80000 N/rad | 前/后轮侧偏刚度 |

**状态量：** `[x, y, psi, v]`（位置、航向角、速度）

**控制量：** `[delta（前轮转角）, a（加速度）]`

**数值积分：** RK4（四阶龙格-库塔），精度远优于欧拉法，急转弯等瞬态工况下误差不累积，达到论文级仿真标准。

**验证结果：** 以 5 m/s 直行 1 秒后 x=5.00m, y=0.00m ✓

### 轨迹生成器（trajectory_generator.py）

提供四种参考轨迹，返回格式均为 `N×4` 数组 `[x, y, yaw, v_ref]`：

| 函数 | 轨迹类型 | 用途 |
|------|---------|------|
| `generate_straight()` | 直线 | 纵向控制基础测试 |
| `generate_circle()` | 圆形 | 恒定曲率跟踪测试 |
| `generate_s_curve()` | S 形弯道 | 横向控制综合测试 |
| `generate_double_lane_change()` | ISO 3888 双移线 | MPC vs 其他算法对比 |

## 使用方式

```python
from models.dynamic_bicycle_model import DynamicBicycleModel
from utils.trajectory_generator import generate_s_curve

car = DynamicBicycleModel(dt=0.05)
car.set_state(0, 0, 0, 5.0)

traj = generate_s_curve()  # 生成 S 形轨迹

# 更新一步
car.update(delta=0.05, a=0.1)
state = car.get_state()  # [x, y, psi, v]
```
