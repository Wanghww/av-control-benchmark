### 各模块说明

**运动学自行车模型（bicycle_model.cpp）**
- 欧拉积分，状态量 `[x, y, θ, v]`
- 对比 Python 版动态模型：更简洁，无轮胎侧偏力项
- 适合 MPC 线性化预测（第四阶段使用）

**PID 控制器（pid_controller.cpp）**
- 增加积分限幅（±10）防止积分饱和
- 与 Python 版参数完全一致（Kp=1.5, Ki=0.1, Kd=0.05）

**Pure Pursuit 控制器（pure_pursuit.cpp）**
- 支持 `min_idx` 参数防止最近点向后跳
- 通过 `lastNearestIdx()` 将当前最近点传回主循环

**Stanley 控制器（stanley_controller.cpp）**
- 新增算法，同时修正航向误差和横向误差
- 原理：`δ = θ_e + arctan(k·e_y / (ks + v))`
- 斯坦福 DARPA 挑战赛冠军车使用的算法

### 仿真结果对比

| 指标 | Python（动态模型）| C++（运动学模型）|
|------|-----------------|----------------|
| RMSE | 0.33 m | **0.065 m** |
| 模型复杂度 | 动态（含轮胎力） | 运动学（几何约束） |
| 积分方法 | RK4 | 欧拉 |

C++ 版 RMSE 更低，因为运动学模型比动态模型更理想化，控制器更容易跟踪。实车测试应以动态模型结果为准。

## 第八周预告

用 stdin/stdout 管道把 C++ 控制器接入 CARLA Python 脚本：
- Python 读取 CARLA 车辆状态 → 写入 C++ 进程 stdin
- C++ 计算控制量 → 输出到 stdout
- Python 读取输出 → 发送给 CARLA
