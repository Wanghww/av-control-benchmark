## 关键发现

**1. 动态模型下控制器差距显著扩大**

运动学模型（第五阶段）：PP vs LQR 差距约 **6%**
动态模型（本阶段）：PP vs LQR_dyn 差距 **39%**（15 m/s）

验证了三层迭代的核心假设：仿真精度越高，控制器差距越显著。

**2. MPC 的多步预测自然吸收了惯量影响**

MPC_kin（无专门适配）在 15 m/s 下 RMSE = 0.081，比 PP 低 43%。
原因：MPC 的 N=10 步预测在多步累积下间接补偿了横摆惯量，即使用运动学线性化也有效。

**3. LQR 动态适配（Bc1·dt²）的工程意义**

运动学 B[1] = v/L·dt 在高速时高估了转角对航向的单步影响（0.278 @15m/s）。
动态 B[1] = Bc1·dt² = 0.072（与速度无关），正确捕捉了轮胎力矩的物理限制，导致 DARE 算出更大的 K，在极高速时（18 m/s）略优于运动学 LQR。

**4. 轨迹图直观展示差异**

15 m/s 双移线：PP 在换道峰值处超调约 8%（3.8m vs 3.5m 参考），回位段有明显振荡；LQR_dyn 全程紧贴参考。

## 动态模型核心实现

### DynamicBicycleModel 状态量

```
State { x, y, theta, v, beta, yaw_rate }
              ↑             ↑        ↑
       与运动学共有      新增：质心侧偏角  横摆角速度
```

### 关键设计决策

**低速退化**：`v < 0.5 m/s` 时自动切换运动学近似，避免 `1/v` 数值奇异。

**RK4 积分**：高速时使用四阶龙格-库塔积分，精度远优于欧拉法（误差 O(dt⁴) vs O(dt)）。

**linearize(v)**：返回 (Ad, Bd) 供 LQR/MPC 使用：

```
连续时间横向动力学（状态 [beta, r]）：
  dbeta/dt = -(Cf+Cr)/(mv)·beta + ((Cr·lr-Cf·lf)/(mv²)-1)·r + Cf/(mv)·δ
  dr/dt    = (Cr·lr-Cf·lf)/Iz·beta - (Cf·lf²+Cr·lr²)/(Iz·v)·r + Cf·lf/Iz·δ

欧拉离散化：Ad = I + Ac·dt，Bd = Bc·dt
```

### LQR 动态适配（computeDynamic）

运动学 vs 动态线性化的关键差异：

| 版本 | B[1]（e_theta 对 δ 的响应） |
|------|-----------------------------|
| 运动学 | `v/L · dt = v/2.7 × 0.05` |
| 动态适配 | `Cf·lf/Iz · dt = 60000×1.2/2500 × 0.05 = 1.44 rad/s per rad · dt` |

动态版本正确捕捉了**轮胎力限制下的横摆响应**，在高速时更能预测实际车辆行为。
