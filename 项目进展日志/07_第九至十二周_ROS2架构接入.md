## 系统架构

```
轨迹发布节点                  控制器节点                  仿真桥接节点
(trajectory_publisher)       (controller_node)          (sim_bridge_node.py)
        |                           |                           |
        |──── /trajectory ─────────>|                           |
        |     S形轨迹300个路点        |──── /vehicle_cmd ────────>|
        |                           |     throttle/steer/brake  |── 动态自行车模型步进
        |<──── /vehicle_state ────────────────────────────────  |
              x, y, theta, v（20Hz）
```

各节点独立进程，通过 ROS2 话题解耦通信，与工业界自动驾驶软件架构一致。

## 各周工作内容

### 第九周：ROS2 环境安装

- 安装 ROS2 Humble（Ubuntu 22.04）
- 配置 `~/.bashrc` 自动加载 ROS2 环境
- 验证 `ros2 --version` 正常

### 第十周：自定义消息包

创建 `av_control_msgs` 包，定义三种自定义消息：

| 消息 | 字段 | 用途 |
|------|------|------|
| `Trajectory.msg` | x[], y[], yaw[], v_ref[] | 规划模块发给控制模块的参考轨迹 |
| `VehicleState.msg` | x, y, theta, v | 仿真器发布的当前车辆状态 |
| `VehicleCmd.msg` | throttle, steer, brake, delta, accel | 控制器发布的执行指令 |

编译验证：`ros2 interface show av_control_msgs/msg/VehicleCmd`

### 第十一周：ROS2 节点实现

**控制器节点（C++）：**
- 复用第二阶段 C++ 控制器（Pure Pursuit + PID）
- 订阅 `/trajectory` 和 `/vehicle_state`
- 20Hz 定时器计算控制指令，发布到 `/vehicle_cmd`
- 支持通过 ROS2 参数动态配置控制器类型和参数

**轨迹发布节点（C++）：**
- 生成 S 形参考轨迹（300 个路点，100m 长）
- 1Hz 发布到 `/trajectory`

**仿真桥接节点（Python）：**
- 复用第一阶段 `DynamicBicycleModel`
- 订阅 `/vehicle_cmd`，推进仿真模型一步
- 20Hz 发布车辆状态到 `/vehicle_state`

CMakeLists.txt 修复：使用 `$ENV{HOME}` 引用 cpp_controllers 路径。
