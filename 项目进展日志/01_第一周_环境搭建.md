## 日常工作流

### 每次开始工作前

**如果第二台电脑重启过**，需先在第二台电脑执行：

1. 打开 WSL2 终端，启动 SSH：
```bash
sudo service ssh start
```

2. 以管理员身份打开 PowerShell，刷新端口转发：
```powershell
$wslIp = (wsl hostname -I).Trim()
netsh interface portproxy delete v4tov4 listenport=2222
netsh interface portproxy add v4tov4 listenport=2222 listenaddress=0.0.0.0 connectport=2222 connectaddress=$wslIp
```

**如果第二台电脑没有重启**，跳过以上步骤。

### 连接 VS Code

当前电脑打开 VS Code → 左下角 `><` → Connect to Host → `wsl-second` → 输入 wangh 的密码。

### 运行 CARLA 仿真时

1. 第二台电脑 Windows 上启动 CARLA：
```powershell
cd D:\CARLA_0.9.15\WindowsNoEditor
.\CarlaUE4.exe
```
等待仿真窗口出现（第一次约 2-3 分钟编译 Shader）。

2. VS Code 终端（WSL2）里运行 Python 脚本，连接地址用：
```python
carla.Client('172.22.0.1', 2000)
```
注意：WSL2 连接 CARLA 必须用 `172.22.0.1`，不能用 `localhost`。

### 代码同步

```bash
# 当前电脑推送
git push

# 第二台电脑拉取
git pull
```
